# Wrestling Coach — project handoff

Football-Manager-style college wrestling coach game. Text-based match sim in the spirit of WMMA5. **Read this whole file first.**

## Decisions made with the user (don't re-litigate)
- **Platform:** browser app, plain ES modules, no build step (Node is NOT installed). Serve with `py -m http.server 8765` from this folder, open http://localhost:8765/ . Headless testing: Edge (`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe --headless=new --virtual-time-budget=60000 --dump-dom URL`) against throwaway `_test.html` / `_ui.html` pages that import the modules (or click through the real UI) and write results into a `<pre>`; delete them afterwards. For long Python patch scripts use a file in the scratchpad (inline heredocs with quotes broke the shell).
- **Scope v1:** NCAA D1, men's, folkstyle only. Later: women's, other divisions, an international freestyle coaching mode.
- **Names:** real school names; real rosters (see Real rosters pipeline) for 78 of 82 schools, the rest generated with the Flo top-16 overlaid. Real entries carry `w.real = true`; `REAL_NAMES_ENABLED` (data/realtop.js) and the start-screen checkbox control it, so the game can be anonymised for sharing.
- **Match viewing:** streamed text play-by-play AND a "Jump to result" button.
- **Takedown = 3 points** (NCAA D1 adopted it; the user was right, I was wrong). `RULES` in bout.js.
- **Tournament dates follow WEEKDAY rules** (data/tournaments.js) so dates shift by year; 2026 reproduces the real dates (Cliff Keen Dec 4-5, Midlands Dec 29-30 verified; Scuffle Jan 2-3 inferred). Conference = first Saturday of March; NCAA = Thu-Sat of third week of March.
- **Save size matters:** play-by-play/replay data is dropped after an event (`pruneReplays`); only results/box scores persist. Season rollover discards old schedule/tournament data (keeps `G.history`, `G.alumni`). A full save is ~1.2MB (localStorage limit ~5MB).
- **Recruit state talent uses real data:** FloWrestling 2025 NCAA qualifiers by home state (PA 41, OH 27, NJ 26, CA 26, IL 24, ...) in data/states.js — drives both recruit counts per state and quality boost.
- **User's priorities:** match engine realism, recruiting logic, AI recruiting/lineup/training logic; injuries; weight-class moves (max ONE per season, ~5 weeks, via weekly training; tiny offseason growth chance). User is often away; keep working autonomously and report at the end. Style: concise, recommendation with options, say what was and wasn't verified.

## Target board + weekly recruiting loop (added 2026-11-08)

## Recruiting balance pass (2026-11-08)
Headless sims (8 seeds x full class, AI-only; plus 5 straight seasons through the real offseason) found: **before** — 61% of the class went unsigned and *no* 5★ signed anywhere (every AI team chased the same 4 top-scored recruits forever; the ask of 100% aid for a 5★ was beyond what top programs' remaining scholarship room could cover, so elites went unsigned); no per-weight limit (3-4 at a weight happened); once I added a late scramble the aid-rich low-prestige programs stole 5★s. **Now:** `MAX_INCOMING_PER_WT` 2, `MAX_AT_WT` 4 (returning non-seniors + incoming), `MAX_CLASS` 8 (all in recruit.js `weightSlots`/`hasWeightRoom`, enforced at commit for AI *and* user; user offers are refused if there is no room). AI weekly targets skip full weights and recruits it already offered (rotate down the list), with a stable per-team taste (`hash(tid+rid)`). `STAR_AID` = 5★ .75 / 4★ .5 / 3★ .25 / 2★ .25 / 1★ 0. `finalizeRecruits` runs a signing-day scramble (`r.late`): programs with room take unattached recruits at the usual ask or whatever aid they can spare (one 0.25 step below the ask), scored by fit + prestige-attainability. Results (commits/team by prestige tier): 85+ 8.0, 70-84 8.0, 55-69 5.7, 40-54 2.9, <40 2.7; top-5 teams hold 12% of all commits; 5★ split ~40% tier A / 46% tier B / rest C; 99% of the class signs; ~39% of signees come in the scramble (62% commit before signing day); no weight ever above 2 incoming. Remaining quirks: A and B tie in volume (both hit the class cap, A wins on quality); tier D/E classes are mostly 1-2★ and they fill rosters with walk-ons; the sim harness was throwaway (deleted) — rebuild from `processRecruitingWeek` x lastDualWeek + `finalizeRecruits` if retuning.

## Prestige drift (2026-11-08)
`js/game/prestige.js` (`applyPrestige`, called from `startNewSeason`; replaces the old +2/+1/-1 by power rank). Expectation-based: expected finish = rank by current prestige; actual = NCAA team finish (70%, teams with no points count as last) + dual-record rank (30%, win% then margin), on a log-rank scale. `K=4`, one-season cap +-2.0, banner floors (title >= +0.75, top-3 >= +0.4, top-5 >= +0.2), clamp 30-99, prestige now stored with 1 decimal (UI rounds for stars). User gets an inbox note. Headless tests: a #30 team with one great year (5th at NCAAs) gains ~+1.1 and gives back ~0.1/yr after; one poor year costs ~-0.8 (mid) / -1.8 (top-10); 3 straight great years moves a mid program ~+3.4 (rank 30->25), 3 poor ones ~-2.3. 12 AI seasons x 3 seeds: prestige SD 16.4 -> ~15.7, mean drift +0.25, no AI team moved >10 net. A passive user team (no recruiting/training) fell ~18 in 12 years (intended). Low-prestige teams barely lose prestige (no NCAA points is already expected). Knobs: `K`, `MAX_STEP`, `W_NCAA/W_SEASON`. Test page was throwaway (deleted).

## Stats, ratings, weight-class polls (2026-11-08)
`js/game/stats.js`. Every simulated bout (all duals incl. AI, all tournament bouts; forfeits excluded) calls `recordBout`, which updates per-wrestler `w.st` (14-number array, order in `KEYS`: w,l,fall,tf,md,dec,td,esc,rev,nf,pf,pa,aa,ch) and `w.elo` (starts at 1500 + (OVR-12)*80, K=20, falls/TF/MD count more; regresses 60% toward new OVR each offseason). NCAA placements add AA/title counts (`recordPlacement`). `rollSeasonStats` (in `startNewSeason`, before `G.season++`) archives `w.st` into `w.hist` `[[season,...st]]`; career = hist + st (`careerOf`). Graduating user seniors get `car` on their `G.alumni` entry. Nothing here feeds the bout engine (no rng use), so results are unchanged. Real wrestlers' pre-game careers are not known, so career starts when the game does.
**Polls:** `G.rkCur`/`G.rkPrev` = `{weight: [top 25 ids]}`, refreshed by `updatePolls` each `finishWeek` and at new-season start (preseason; movement vs last season's final). Each wrestler is polled at the weight he last wrestled (else his lineup spot); ranked by Elo. Lazy `ensurePolls` covers old saves (no migration needed).
**UI:** Rankings has Teams / Weight classes tabs (top 25, move ▲▼/NEW, record, pins, OVR); new Stats screen: My team (sortable columns, team total row) and National leaders, each for This season / Career. Save cost of stats ~100KB for 2 seasons. Verified headlessly (2 seasons: wins == losses, 80 AA + 10 champs per year, UI click-through). Ideas: poll-based NCAA seeding, individual wrestler profile page with season-by-season line, conference/dual-meet MOP awards.

## Pin-rate retune (2026-11-08)
The stats page exposed that **19-20% of league bouts ended in falls** (the old equal-12s calibration hid it; skill gaps drive pins). Pin odds per near-fall are now the exported tunable `PIN` in bout.js: `clamp(base + adv*gap + (str-10)*strK, min, max) * (3+ pt NF ? bigMult : 1)`. Old: base .10 / adv .018 / bigMult 1.35. **New: base .035 / adv .008 / bigMult 1.2.** Method: sampled 4000 same-weight starter pairs from a generated league (plus a top-45% "tournament" pool), swept PIN values. Results (league mix): falls 9.2% of duals (was 20.1%), 6-7% between near-equals, ~15% at 3.5+ OVR gaps (was 34%); full real season measured 8.3% falls / 2.7% TF / 25% MD / 64% other decisions. Takedowns/bout unchanged (~2.7). **Still off / not touched:** MD ~25% (real D1 maybe 15-18%) and ~1.0 near-falls per bout look high — that is the next lever (NF frequency/points in `exposure()`/top-position logic), and it rose a bit when pins dropped. The engine doesn't distinguish tournament vs dual pin rates (real NCAA pins are lower). The old "Fall ~9% at equal 12s" calibration number in Status is obsolete (now ~6%); win-rate/other calibration was not re-run.

## Schedule balance + offseason schedule editor (2026-11-08)
- **Builder (`makeSchedule`)** now balances load. Measured over 4 seasons x 78 teams, regular season through the conference tournament, one starter per weight: **~90% of starters wrestle 18-35 matches** (p5 17, median 27, p95 35, max ~50), ~6% below 18 and ~4% above 35 (bracket luck: early exits / deep consolation runs, injuries); team averages 18.6-35.9, none under 18. The header shows duals, events and the projected matches for a starter (target 18-35, good/light/heavy).
